## Hey there!👋 

I'm a **PHP Laravel Developer** with 4+ years of professional experience building, maintaining, and improving web applications and RESTful APIs.

I specialize in PHP, Laravel, and CodeIgniter, with strong experience in MySQL, PostgreSQL, MVC architecture, OOP, Eloquent ORM, authentication, API development, and database optimization.

I have hands-on experience developing backend modules, integrating third-party APIs, troubleshooting production issues, optimizing database queries, and implementing asynchronous workflows using Laravel Queues, Jobs, Events, and Task Scheduling.

I can also integrate backend services with frontend applications using HTML, CSS, JavaScript, Bootstrap, jQuery, and AJAX. My experience includes application testing, unit and integration testing, debugging, Git-based workflows, and collaborative development.

I focus on writing clean, maintainable, secure, and performant code while delivering reliable solutions that meet project requirements.
